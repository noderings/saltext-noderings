NodeRings Salt Extension
========================

Manage `NodeRings <https://noderings.com>`_ from SaltStack: order servers from
the NodeRings cloud marketplace with Salt Cloud, and keep DNS zones and records,
firewall rulesets, SSH keys and virtual machines in Salt states.
